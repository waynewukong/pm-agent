# deliverables

这个目录存放具体需求的交付物。

## 当前内容

- `presale-actual-sale-material-no/`：用户预实销模块导出新增物料号字段需求

## 约定

- 每个需求使用单独文件夹
- 文件夹内至少包含 `README.md`
- 推荐包含：`prd.md`、`testcases.md`、`revision-log.md`

## 使用方式

- 新需求进入时，先新建一个独立目录
- 再按模板产出 `prd.md`
- 如需要评审与回归，再补 `testcases.md`
- 有多轮反馈时，持续维护 `revision-log.md`
